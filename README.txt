В папке уже есть все, что нужно:
- index.html
- styles.css
- assets/ — изображения 7 слайдов
- portfolio.pdf — чистовая PDF-версия

КАК ЗАГРУЗИТЬ

1. Распакуйте ZIP на компьютере.
2. В репозитории GitHub удалите старый пустой index.html и старые HTML-файлы.
3. Нажмите Add file → Upload files.
4. Перетащите СРАЗУ содержимое папки portfolio-github:
   index.html
   styles.css
   portfolio.pdf
   папку assets
5. Нажмите Commit changes.
6. Подождите 1–2 минуты и откройте:
   https://sandakovatatyanya.github.io/portfolio/
